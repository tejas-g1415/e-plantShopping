# Paradise Nursery Shopping Application

Paradise Nursery is a React-based online plant shop where visitors can explore indoor plants, browse them by category, and manage a shopping cart.

## Features
- Landing page with company introduction and Get Started button
- About Us section
- 18 plants across three categories: Air Purifying, Low Maintenance, and Succulents
- Product thumbnails, names, descriptions, and prices
- Add to Cart buttons that disable after adding a product
- Shared navigation across the Plants and Cart views
- Dynamic cart item count, quantity controls, item subtotals, and grand total
- Remove item, Continue Shopping, and Coming Soon checkout message
- Redux Toolkit for centralized cart state

## Tech stack
- React + Vite
- Redux Toolkit
- React Redux
- CSS

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```

Plant photographs are loaded from Unsplash image URLs and therefore require an internet connection to display.
